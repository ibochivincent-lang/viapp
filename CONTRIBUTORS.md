## 🌟 How to Join the Contributor Ladder

1. Pick an issue tagged [`wave-10`](https://github.com/viappToken/viapp/labels/wave-10) or [`good-first-issue`](https://github.com/viappToken/viapp/labels/good-first-issue).
2. Read the [Contribution Guidelines](./CONTRIBUTING.md).
3. Submit a pull request with passing automated tests.
4. Once merged, submit a PR to add your name and Stellar public key to this ledger!
