## For a Friend (Recipient)

Someone sent you a tokenized stock gift link. You do not need an existing wallet, browser extensions, or any crypto.

1. **Open the Gift Link:** Open `https://<site>/g/<giftId>#<claimKey>`.
2. **Sign In:** Tap **"Sign in to open it"** with your Google account, email, or a biometric device passkey. ViApp creates a non-custodial Stellar wallet for you in under 5 seconds.
3. **Declare Eligibility:** Check the box confirming you are not a US person and not located in a restricted/sanctioned jurisdiction.
4. **Claim Your Stock:** Tap **"Open your gift"**. ViApp's relayer submits the claim transaction to the Stellar network and sponsors all network gas fees.
5. **Ownership Confirmed:** You see your certificate seal, the exact fractional share count, the sender's encrypted note, and a live verification link on [Stellar Expert Explorer](https://stellar.expert/explorer/testnet/contract/CDEDHFJ7POEWDFFDRV74ZIWK4CSDKGEN4B4IQXUZHMKGVMJIVFODEV5M).
6. **Flexible Actions:** You can hold your equity, instantly liquidate to native Stellar USDC on SDEX, or cash out at physical MoneyGram retail locations worldwide.

## For a Sender

You need a Stellar-compatible wallet (Freighter, xBull, Albedo, or WebAuth passkey) funded with USDC or XLM on Stellar.

1. **Visit the Send Page:** Navigate to `/send` and connect your wallet.
2. **Select Tokenized Equity:** Choose Apple (`AAPL`), NVIDIA (`NVDA`), Tesla (`TSLA`), Microsoft (`MSFT`), Amazon (`AMZN`), Alphabet (`GOOGL`), or Meta (`META`).
3. **Choose Gift Amount & Duration:** Select $1, $5, $10, $25, or custom USD. Choose how long the gift stays open (7, 30, or 90 days; default 30).
4. **Write an Encrypted Note:** Add a personalized note (up to 480 characters), sealed with AES-GCM encryption using the ephemeral link key.
5. **Approve & Lock:** Confirm the transaction in your wallet. The stock is locked in the Soroban `viapp-gift-vault` contract.
6. **Share the Link:** Copy the unique gift link and send it via WhatsApp, Telegram, Email, or SMS. If your friend never opens it, you can reclaim your funds after expiry.

## For Hackathon Testers

1. Open the **For Testers** section on the homepage.
2. Sign in with Google or Email (Privy embedded Stellar wallet).
3. Enter your tester authorization token into the input box.
4. Tick the compliance eligibility declaration.
5. Tap **"Claim my share"**. The Soroban smart contract transfers a live share of tokenized stock to your wallet, and ViApp's relayer pays the transaction fees.
6. View the live transaction on [Stellar Expert Explorer](https://stellar.expert/explorer/testnet/contract/CDEDHFJ7POEWDFFDRV74ZIWK4CSDKGEN4B4IQXUZHMKGVMJIVFODEV5M).

## For Developers

### Prerequisites

- **Node.js** 22+ and **npm**
- **Rust toolchain** (`cargo`) with `wasm32-unknown-unknown` target for Soroban smart contracts

### Clone & Install

```bash
git clone https://github.com/ibochivincent-lang/viapp.git
cd viapp
npm install
```

### Run Test Suites

```bash
# Run all TypeScript test suites (508 core tests, 59 agent tests)
npm test

# Run Soroban Rust smart contract test suite (cargo test)
cd packages/contracts/stellar
cargo test
```

### Environment Variables

Copy `.env.example` to `.env` at the repository root:

```bash
cp .env.example .env
```

| Variable | Description |
|---|---|
| `STELLAR_NETWORK` | Network name (`testnet` or `mainnet`). |
| `STELLAR_RPC_URL` | Stellar Soroban RPC endpoint (`https://soroban-testnet.stellar.org`). |
| `STELLAR_VAULT_CONTRACT_ID` | Deployed `viapp-gift-vault` contract address (`CDEDHFJ7POEWDFFDRV74ZIWK4CSDKGEN4B4IQXUZHMKGVMJIVFODEV5M`). |
| `STELLAR_RELAYER_SECRET` | Secret key for the fee-bump sponsor relayer. |
| `NEXT_PUBLIC_PRIVY_APP_ID` | Embedded authentication app ID. |
| `UPSTASH_REDIS_REST_URL` | Ephemeral store for rate limiting and replay protection. |
