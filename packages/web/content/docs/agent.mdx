The ViApp CLI agent (`@viapp/agent`) enables autonomous agents, backend services, and command-line developers to buy, escrow, and gift tokenized stocks programmatically.

---

## Core Capabilities

- **Automated Gifting:** Derives client-side Ed25519 ephemeral claim keypairs, encrypts personalized recipient notes with AES-GCM, and submits escrow transactions to the Soroban `viapp-gift-vault`.
- **Execution Engine:**
  - **Stellar Soroban:** Native transaction submission, contract invocation, and fee-bump sponsorship.
  - **Agentic Wallet Automation:** Headless execution with spend caps and simulation gates.

---

## Quickstart

Run the agent via npm:

```bash
# Check agent status and connected wallet balances
npm run viapp -- status

# Gift $10 of NVIDIA with a 30-day expiration and personalized note
npm run viapp -- gift NVDA 10 --note "Welcome to investing!" --days 30

# Gift stock from currently held balance
npm run viapp -- gift AAPL --use-held 0.05 --note "Happy Birthday"
```

---

## Safety Invariants & Execution Gates

1. **Strict Stock Allowlist:** The agent validates tickers against the on-chain registry of the Soroban vault.
2. **Oracle Circuit Breaker:** Quotes deviating more than 2% from benchmark market feeds are automatically aborted.
3. **Simulation Verification:** Transactions are simulated locally before broadcasting to the network.
4. **Isolated Link Fragments:** Generated gift links store the secret claim key in the `#` fragment, ensuring secrets are never leaked to logs or external APIs.
