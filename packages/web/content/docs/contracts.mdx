## Functions

### Anyone Can Call

| Function | What it does | Error Conditions |
|---|---|---|
| `create_gift(sender, token, amount, claim_key, expiry, sealed_note, key_proof)` | Locks `amount` of a listed token from `sender` as a new gift. Binds the gift to `claim_key`. | Vault is paused; token not listed; amount is 0; key already used; expiry outside valid range (< 1 hr or > 90 days); invalid key proof. |
| `claim(gift_id, recipient, signature)` | Releases an open gift to `recipient`. Can be invoked via the sponsor relayer or directly with a valid signature from `claim_key`. | Gift not open; gift expired; invalid signature; recipient is zero/vault. |
| `refund(gift_id)` | Returns an expired, unclaimed gift back to the original `sender`. | Gift is not expired; gift already claimed or refunded. |
| `get_gift(gift_id)` | Reads a gift record: `(sender, token, amount, claim_key, expiry, state, sealed_note)`. | Never reverts. Returns `None` for non-existent gifts. |
| `listed_tokens()` | Returns the list of all active token contracts allowed in the vault. | Never reverts. |

### Protocol Admin Functions

| Function | What it does |
|---|---|
| `set_token_listed(token, bool)` | Adds or removes a tokenized equity from the active gifting registry. |
| `set_relayer(new_relayer)` | Updates the authorized gasless relayer keypair. |
| `pause()` and `unpause()` | Circuit-breaker to freeze new gift creation during maintenance. |
| `extend_ttl()` | Automatically bumps instance TTL and gift storage TTL across Stellar ledgers. |

## Verification via Stellar CLI

Inspect the live Testnet contract directly with zero setup using the official `stellar` CLI:

```bash
# Query the next gift ID
stellar contract invoke \
  --id CDEDHFJ7POEWDFFDRV74ZIWK4CSDKGEN4B4IQXUZHMKGVMJIVFODEV5M \
  --source-account S... \
  --network testnet \
  -- next_gift_id

# Query the listed token contracts
stellar contract invoke \
  --id CDEDHFJ7POEWDFFDRV74ZIWK4CSDKGEN4B4IQXUZHMKGVMJIVFODEV5M \
  --source-account S... \
  --network testnet \
  -- listed_tokens
```
